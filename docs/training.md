# 用自己的数据继续训练模型（完整指南）

> **结论先说：这条路完全可行，而且是本项目推荐的使用方式。**
> 但它不是"喂几张图就自动变聪明"——需要你**画边界**（每张 5–10 秒），
> 一般 **50 张左右**就能看到明显提升，CPU 训练 **几分钟**。

---

## 一、为什么可以这样做

本项目的自动识别分两步：

```
照片 ──► SAM 分割模型 ──► 自动掩膜 ──► 边界细化模型(U-Net) ──► 最终边界
                                        ↑
                              这一层是"可训练"的
```

**细化模型**就是把"自动掩膜"修正成"人工认为正确的边界"。
你标注的每一张图，都是在教它：**遇到这种情况该扩到哪里 / 该收多少**。

实测（53 张标注数据，3 折交叉验证，留出验证）：

| 方案 | 平均误差 MAE | 中位误差 |
|---|---|---|
| 只用 SAM 自动掩膜 | 33.8 mm | 30.3 mm |
| **加上细化模型** | **11.6 mm** | **6.3 mm** |
| 提升 | **−66 %** | −79 % |

训练成本：CPU，不到 1 分钟。**不需要显卡，不需要大数据。**

## 二、完整流程（5 步）

### 第 0 步：安装依赖
```bash
pip install -r requirements.txt
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

### 第 1 步：用程序测一遍你的图片
```bash
python app/app.py "D:\photos"
```
程序会在照片目录下生成：
```
photos/菌落测量输出/
├── auto_masks/1.png, 2.png ...     ← 自动掩膜（训练要用）
└── measurements.csv                ← 逐图直径/状态
```

> 用**高精度模式**（默认）跑一遍，自动掩膜质量更好，训练效果也更好。

### 第 2 步：用「标注模式」打开，把边界画对
> 程序默认打开的是**给最终用户的简洁结果页**（不能画边界）。
> 要标注请加 `--annotate` 参数：

```bash
python app/app.py --annotate "D:\\photos"
```

浏览器打开标注页：
- 圈对的：点「边界正确」，**不用画**（但建议也留一些，见第 4 步）
- 圈错的：用 **圆形 / 多边形 / ✏️涂抹** 重画；细毛满皿的直接「一键满皿」
- 只想修正直径、不想画整个边界：用 **📏 两点测距**，点两下画横径、再点两下画竖径
  （支持边缘吸附 + 4× 放大镜）。这类标注在构建训练集时会**按测得直径等比例缩放原掩膜**，
  保留不规则形状，不会变成标准圆。
- 全部过一遍后，点 **导出CSV**（这个 CSV 就是训练用的标注）

这个 CSV 就是你的**人工标注（ground truth）**。

### 第 3 步：构建训练集
```bash
python scripts/build_mask_dataset.py \
  --annotations "D:\photos\人工框取.csv" \
  --images      "D:\photos" \
  --base-mask-dir "D:\photos\菌落测量输出\auto_masks" \
  --out-dir     "D:\dataset"
```
输出：`D:\dataset\*.npz`（每个样本 = 原图裁切 + 自动掩膜 + 目标掩膜）
以及 `index.csv`，里面能看到每条样本的来源与"自动 vs 人工"直径，方便核对：

| source | 含义 |
|---|---|
| `manual` | 你画的边界（难例修正） |
| `auto_identity` | 程序自动补的"保持不动"样本，**零额外操作** |

> 两点测距标注（`type=line`）不会画成圆：脚本会把自动掩膜围绕质心缩放到你测得的直径，
> 保留原有的不规则轮廓。

### 第 3.5 步：合并多个数据集前，先检查

```bash
python scripts/check_dataset.py --dataset "D:\dataset"
```

它会报告 `base/man` 面积比分布，并列出空掩膜的坏样本。

> **重要经验**：比值大不一定是坏数据——"SAM 只圈到菌饼、人工是满皿"就是我们要学的难例。
> 但如果这类**极端样本（比值 > 10）占比超过 15~20%**，模型会学成"一律放大"，
> 把本来正确的图也吹大。合并数据集时要么控制比例，要么单独加权，不要直接堆在一起。

### 第 3.6 步：挑难例必须用「当前版本」的结果

> 实测教训：用三个月前的 v9 结果挑出 54 张"难例"，标完并入训练集后，
> 交叉验证反而从正提升变成 **-14.7%**。
> 原因：这 54 张在当前版本下其实已经测得很准（平均只差 1.92 mm），
> 标了等于反复教模型"保持不动"，反而放大了它对正常图的扰动。
>
> **规则**：每次要补数据，先跑一遍**当前版本**，从这次结果里挑，
> 不要拿旧版本的失败案例。

### 3.7 绿圈完全错误时，两点测距不够

两点测距只提供**中心 + 直径**，不提供真实边界形状。`build_mask_dataset.py` 会按直径缩放原自动掩膜，并把质心移到测距线中点。

如果原掩膜是**整皿/皿边/皿盖**，缩放后会变成一个小圆，等于教模型“看到大盘就缩小”。实测这会在大菌落上造成灾难性回退（73.9 mm → 17.7 mm）。

规则：
- 绿圈只是偏大/偏小、位置大致正确 → 两点测距可用
- 绿圈完全圈到皿边/皿盖、或圈到别的菌落 → **必须用涂抹/多边形**画真实边界
- 脚本默认 `base/man > 8` 会跳过这类两点测距样本，并提示改用涂抹/多边形（`--max-base-man-ratio` 可调）

### 第 4 步：训练
```bash
python scripts/train_mask_refiner.py \
  --dataset "D:\dataset" \
  --out "models/refine_unet.pt" \
  --epochs 30 --folds 3 --seed 0
```
> 加 `--cv-only` 只跑交叉验证、不训练最终模型，用于快速评估。
> 脚本会读取 `--dataset` 下**所有子目录**的 npz（包括 `identity/` 保持样本）。
控制台会打印交叉验证结果，例如：
```
自动掩膜   MAE = 59.8 mm（中位 37.7）
细化模型   MAE =  9.0 mm（中位  2.7）
提升       84.9%
```
看到"提升"是正数，就说明训练有效。

### 第 5 步：让程序用上新模型
把生成的 `refine_unet.pt` 复制到程序的 `models/` 目录（覆盖同名文件）即可，
**代码不用改**。下次测量就会用你的模型。

## 三、需要多少数据？

| 标注张数 | 预期效果 |
|---|---|
| < 20 | 提升不明显，容易过拟合 |
| **50 左右** | **能看到明显提升**（本项目实测起点） |
| 100–300 | 比较稳定，建议目标 |
| > 500 | 进一步提升空间有限，除非换了新场景 |

**不需要标注全部图片**。建议：
- 把**自动圈错的那批**（程序标"需复核"的）全部标注
- 另外**随机挑 20–30 张"自动圈对"的**也标注一下（见下）

## 四、关键注意事项（很重要）

### 1）"对的图"由程序自动补上（你什么都不用做）
只标注框错的图，模型会学成**"永远把边界放大"**，在本来正确的图上帮倒忙。
本项目就踩过这个坑：只放难例时，自动接受组被平均改动 18 mm。

**现在程序会自动处理**：测量时它已经把"自动掩膜"和"状态"存到了
`菌落测量输出/`；`build_mask_dataset.py` 会**自动把状态=自动的图**
按"保持不动"（标注 = 自动掩膜）加进训练集：

```
完成：人工标注样本 4 个 + 自动保持样本 4 个 -> D:\dataset
```

> 数量上限默认为"人工标注数 × 1.0"，可用 `--identity-ratio` 调整，
> 用 `--auto-identity 0` 关闭。所以**你只需要标注错的那批，保持样本自动补齐。**

（想更保守的话，也可以自己额外标 20–30 张正常图，效果一样。）

### 2）基础掩膜质量决定上限
细化模型是"在自动掩膜基础上修正"。如果 SAM 完全没找到菌落（掩膜是空的），
模型只能靠图片自己找，效果会打折。所以尽量先用**高精度模式**跑一遍。

### 3）域偏移：每个实验室的数据不一样
光照、培养基颜色、拍摄距离不同，模型表现会下降。
**别人的模型不一定适合你**——这正是需要"自己标注自己训练"的原因。

### 4）先看交叉验证，再全量训练
脚本默认会做 3 折交叉验证并打印提升比例。
**如果提升是负数**，说明：
- 样本太少 → 再加数据
- 只有难例没有正常图 → 按第 1 条补
- 标注质量不一致 → 检查是否有画错的

### 5）训练完记得保留原始模型备份
`models/refine_unet.pt` 被覆盖后，想回退需要重新下载本仓库。

## 五、常见问题

**Q：没有显卡能训练吗？**
A：能。本项目在 CPU 上训练 41 个样本、3 折交叉验证 + 全量训练，总共约 3.5 分钟。

**Q：会越训越差吗？**
A：脚本会打印留出验证的提升比例，为负就不要用这个模型。
另外保留旧模型备份，随时可以换回来。

**Q：每次都重新训练，还是可以持续累积？**
A：把新的标注 CSV 累加起来（同一格式），重新生成数据集再训练即可。
建议保留一个"总标注集"，越攒越强。

**Q：能不能不用 SAM，只训练一个从图片直接出边界的模型？**
A：可以——`build_mask_dataset.py` 不传 `--base-mask-dir` 时，基础掩膜用全零，
模型就变成"看图直接分割"。但样本少时效果不如"SAM + 细化"两步走。

**Q：模型文件多大？**
A：约 1.9 MB。很轻，可以随项目一起分发。
